# FlipRadar (Fabric, Minecraft 26.2)

Клиентский мод для Hypixel SkyBlock. При запуске игры поднимает локальный дашборд на http://127.0.0.1:8765/
(только localhost), который показывает лучшие флипы на базаре и аукционе (BIN). Команда в игре: `/flips`.

Данные: публичное API Hypixel (ключ не нужен). Мод ничего не автоматизирует — только показывает.

## Сборка
1. Установи JDK 25.
2. Самый надёжный путь: на https://fabricmc.net/develop сгенерируй шаблон под 26.2 и перенеси в него
   папку `src/` из этого архива (и сверь версии в gradle.properties).
   Либо в этой папке выполни `gradle wrapper` и затем `./gradlew build`.
3. Готовый jar: build/libs/flipradar-1.0.0.jar -> в папку mods (нужен Fabric API).

## Настройка
- Налог базара в дашборде: по умолчанию 1.25%, поменяй под свой апгрейд Bazaar Flipper.
- Налоги аукциона заданы в AuctionFlips.fees() — сверь с вики.

## Получить jar без установки Java (GitHub Actions)
1. Создай пустой репозиторий на github.com и загрузи в него все файлы из этой папки (включая .github).
2. Вкладка Actions -> build -> дождись зелёной галочки.
3. Внутри запуска скачай артефакт flipradar-jar (внутри будет flipradar-1.0.0.jar, а sources-jar не нужен).
4. Положи jar в папку mods вместе с Fabric API 26.2.
Если сборка упадёт, открой лог и пришли мне текст ошибки.
